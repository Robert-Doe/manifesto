What to verify

  • ✓ The NeuralTab icon appears in the Chrome toolbar (you may need to pin it from the puzzle-piece menu)
  • ✓ Clicking the icon opens a dark popup — not a blank page or an error
  • ✓ The popup shows this page's full URL in the "Active Tab" section
  • ✓ The popup shows this page's title ("NeuralTab — Module 01 Demo Page")
  • ✓ The "Extension Info" section shows a real extension ID (a 32-character string)
  • ✓ Clicking "Set ON" turns the toolbar badge green with the text ON
  • ✓ Clicking "Count" repeatedly increments the badge number
  • ✓ Clicking "Clear" removes the badge entirely
  • ○ After completing the exercises in tutorial.html, the badge also updates on page load automatically
