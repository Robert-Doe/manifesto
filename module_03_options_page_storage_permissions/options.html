Permissions

Optional capabilities that unlock additional NeuralTab features. You can grant or revoke these at any time.

📑
Read all tab URLs & titles
Required for the Tab Manager feature (Module 04). Allows NeuralTab to read the URL and title of every open tab — not just the active one. Without this, background tabs show as "(restricted)" in the Tab Manager.
Why you might want this: The Tab Manager lists, searches, and de-duplicates all your open tabs. That requires reading all tab URLs, which needs this permission.
Not granted
🔖
Read & write bookmarks
Required for the Bookmark Organiser feature (Module 04). Allows NeuralTab to read your bookmark tree and create/move/delete bookmarks.
Why you might want this: The Bookmark Organiser can automatically group your bookmarks by domain and remove duplicates.
Not granted
📅
Read browsing history
Required for the History Search feature (Module 04). Allows NeuralTab to search your browsing history by keyword and date range.
Why you might want this: Find any page you visited in the last 90 days by searching keywords — faster than Chrome's own history search.
Not granted
How Optional Permissions Work

NeuralTab requests these permissions only when you click Grant above — never at install time. Chrome shows a targeted permission dialog explaining exactly what will be granted. You can revoke any permission at any time by clicking Revoke, without affecting other features. This is the "warm ask" pattern: show the user the value of the permission before asking, then ask with a single targeted click.
