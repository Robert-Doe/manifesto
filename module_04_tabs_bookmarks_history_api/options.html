Permissions

These permissions are optional. NeuralTab asks only when you need the feature, and only after showing you what it enables.

🗂
Read all tab URLs & titles
Enables the Tab Manager: see all open tabs, group by domain, detect idle tabs, close tabs in bulk, and get idle-tab notifications.
★
Read & write bookmarks
Save tabs directly from the Tab Manager into a "NeuralTab Saves" folder. Also lets the Tab Manager show your 10 most recent bookmarks in the sidebar.
🕐
Read browsing history
Adds a history search panel to the Tab Manager so you can quickly find and reopen recently visited pages.
🔔
Show desktop notifications
Sends a system notification when the 30-minute alarm detects 5 or more idle tabs. Clicking the notification opens the Tab Manager.
