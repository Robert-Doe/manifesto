Module 11 — Extension Fingerprinting

How pages detect installed extensions — and how to reason about your extension's detectability.

WAR-Based Detection

Any URL in web_accessible_resources can be probed by any page:

// Page script can detect your extension is installed:
const img = new Image();
img.onload  = () => console.log('NeuralTab IS installed');
img.onerror = () => console.log('NeuralTab not installed');
img.src = 'chrome-extension://KNOWN_EXTENSION_ID/assets/inject.js';

Timing-Based Detection

Even without knowing the extension ID, pages can detect content script injection by measuring DOM mutation timing. Extensions that add DOM elements or modify styles leave a detectable latency signature.

Reducing Your Footprint

Minimize WAR entries. Only expose files that truly need to be accessible from web pages. The fingerprint.html page shows NeuralTab's current exposure surface — the detectability score drops as WAR entries are removed.
