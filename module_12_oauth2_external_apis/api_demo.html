Auth Flow Diagram
1
Extension calls chrome.identity.launchWebAuthFlow({ url: googleAuthUrl, interactive: true })
2
Chrome opens a pop-up to Google's OAuth endpoint. User logs in and consents.
3
Google redirects to https://<ext-id>.chromiumapp.org/ with #access_token=…
4
Chrome intercepts the redirect and returns the URL to the extension. Extension parses the token.
5
Extension stores the token in chrome.storage.local and makes API calls with Authorization: Bearer …
