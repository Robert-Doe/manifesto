Module 12 — OAuth2 & External APIs

launchWebAuthFlow: the extension-native OAuth2 flow that works with any provider, no server required.

The Redirect URI Trick

Extensions get a special redirect URI: https://<ext-id>.chromiumapp.org/. Chrome intercepts redirects to this domain and returns the URL to launchWebAuthFlow. No server, no CORS, no proxy needed. The extension ID is cryptographically bound to your signing key, making this URI unguessable.

Token Lifetime

Google access tokens expire after 1 hour. auth_manager.js handles 401 responses by clearing the stored token and prompting a new login. For silent re-auth (user already has an active Google session), launchWebAuthFlow({ interactive: false }) completes without showing a popup.

Setup Requirements

# 1. Create a Google Cloud project
# 2. Enable the API you want (Gmail, Drive, etc.)
# 3. Create OAuth2 credentials (Web Application type)
# 4. Add authorized redirect URI:
#    https://<YOUR_EXTENSION_ID>.chromiumapp.org/
# 5. Replace CLIENT_ID in auth_manager.js with your OAuth2 client ID
