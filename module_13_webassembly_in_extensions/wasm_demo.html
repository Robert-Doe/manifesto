The WAT Source (WebAssembly Text Format)
(module
  (func $fib (export "fib") (param $n i32) (result i32)
    (if (i32.lt_s (local.get $n) (i32.const 2))
      (then (return (local.get $n)))
    )
    (i32.add
      (call $fib (i32.sub (local.get $n) (i32.const 1)))
      (call $fib (i32.sub (local.get $n) (i32.const 2)))
    )
  )
)

This WAT is compiled to a .wasm binary offline (via wat2wasm or the online wat-studio). The extension ships the .wasm file and loads it at runtime via WebAssembly.instantiateStreaming(fetch(url)).

CSP Caveat — Extensions Are Different
Checking Wasm availability…
# Web pages can use unsafe-eval for Wasm:
Content-Security-Policy: script-src 'unsafe-eval'

# Extension pages CANNOT use unsafe-eval (MV3 restriction)
# But WebAssembly.instantiate() with a .wasm *file* is allowed!
# The restriction is on COMPILING from text strings, not from binary files.
