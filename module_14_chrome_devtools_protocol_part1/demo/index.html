Module 14 — Chrome DevTools Protocol Part 1

Direct access to Chrome's internal debugging engine from your extension.

What CDP Unlocks

The Chrome DevTools Protocol is the same protocol that powers Chrome DevTools, Puppeteer, and Playwright. Your extension gets the same access via chrome.debugger: evaluate JavaScript in any tab, inspect the DOM tree, read cookies, capture performance metrics, and take screenshots.

The Three-Step Pattern

// 1. Attach
await chrome.debugger.attach({ tabId }, '1.3');

// 2. Send commands
const result = await chrome.debugger.sendCommand(
  { tabId }, 'Runtime.evaluate', { expression: 'document.title' }
);

// 3. Detach when done (or on tab close)
await chrome.debugger.detach({ tabId });

The Infobar Warning

Chrome shows an orange "DevTools is connected" banner in any tab where the debugger is attached. This cannot be removed. Design your extension's UX to acknowledge this — tell users why debugging is active and provide a clear way to detach.

Real Use Cases

CDP powers: automated testing tools, performance profiling extensions, accessibility auditors, SEO analyzers (DOM inspection), screenshot tools, and developer productivity extensions. It is the most powerful API in the Chrome extension arsenal — and the most scrutinized by CWS reviewers.
