What CDP Actually Is

Chrome DevTools Protocol is the JSON-RPC protocol that Chrome's DevTools UI uses to communicate with the browser engine. When you open DevTools and click "Elements," DevTools is sending DOM.getDocument over a WebSocket to the browser process. When you set a breakpoint, it's sending Debugger.setBreakpoint. Every action in DevTools corresponds to a CDP command.

Extensions get access to this same protocol via chrome.debugger. Instead of a WebSocket, you use the extension API — but the commands, parameters, and responses are identical to the DevTools protocol documentation at chromedevtools.github.io/devtools-protocol/.

Attaching the Debugger

// Attach to a specific tab at protocol version 1.3
await chrome.debugger.attach({ tabId: someTabId }, '1.3');

// Or attach to a worker:
await chrome.debugger.attach({ targetId: workerTargetId }, '1.3');

// Detach when done — always detach!
await chrome.debugger.detach({ tabId: someTabId });

Only one debugger can be attached to a tab at a time. If Chrome DevTools is already open on that tab, your attach() will fail with "Another debugger is already attached." NeuralTab detects this and shows an error in the CDP inspector.

Sending Commands

// Evaluate JavaScript in the page context
const result = await chrome.debugger.sendCommand(
  { tabId },
  'Runtime.evaluate',
  {
    expression: 'window.location.href',
    returnByValue: true,           // return plain value, not object reference
    awaitPromise: false,
  }
);
console.log(result.result.value);  // "https://example.com"

// Get the DOM tree
const dom = await chrome.debugger.sendCommand(
  { tabId },
  'DOM.getDocument',
  { depth: 3, pierce: false }
);
console.log(dom.root.nodeName);  // "#document"

Receiving Events

Some CDP domains emit events when you enable them. Network.enable causes Network.requestWillBeSent events to fire for every request. These arrive via chrome.debugger.onEvent — a global listener in your background SW.

chrome.debugger.onEvent.addListener((source, method, params) => {
  if (method === 'Network.requestWillBeSent') {
    console.log('Request:', params.request.url);
  }
  if (method === 'Runtime.consoleAPICalled') {
    console.log('Page console:', params.args.map(a => a.value).join(' '));
  }
});
CWS Review Warning

The debugger permission triggers mandatory manual review by Google. Be prepared to justify your use case in the listing description. Extensions that use CDP without a clear developer-tool use case are frequently rejected. Never request this permission "just in case."

The Infobar Is Permanent

Chrome displays an orange infobar in any tab where your extension has the debugger attached: "DevTools is connected to Chrome." This is a deliberate security feature to alert users that their tab is being debugged. You cannot hide it, remove it, or suppress it. Design your extension's UX to acknowledge this — show your own status indicator and provide a clear detach button.

Common CDP Use Cases

// Accessibility auditing
const tree = await debuggerSend('Accessibility.getFullAXTree');

// DOM screenshot
const { data } = await debuggerSend('Page.captureScreenshot', { format: 'png' });

// Performance metrics
await debuggerSend('Performance.enable');
const { metrics } = await debuggerSend('Performance.getMetrics');
const lcp = metrics.find(m => m.name === 'LargestContentfulPaint');

// Cookie inspection
const { cookies } = await debuggerSend('Network.getCookies');

// Intercept console.log from page
await debuggerSend('Runtime.enable');
// then listen for Runtime.consoleAPICalled events

Exercises

Exercise 14-A — DOM Inspection

Use the CDP Inspector to call DOM.getDocument with depth: 10 on a page of your choice. Find the count of all <img> elements by querying DOM.querySelectorAll with selector "img". Display the count in the CDP result panel.

Exercise 14-B — Console Intercept

Add a new button to cdp_inspector.html: "Enable Console Capture." When clicked, call Runtime.enable and listen for Runtime.consoleAPICalled events. Display the captured console messages in the event log. Test by opening the page's DevTools console and typing console.log('hello from CDP').

Exercise 14-C — Auto-Detach on Tab Navigation

The debugger stays attached across navigation — which can cause unexpected behavior. Add a chrome.tabs.onUpdated listener in background.js that automatically detaches the debugger when the attached tab navigates to a new page. Update the UI in cdp_inspector.html to show "detached (navigation)" when this happens.
