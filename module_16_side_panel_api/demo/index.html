Module 16 — Side Panel API

A persistent sidebar that survives navigation — the right UI for features that observe browsing.

Panel vs. Popup

Side Panel
  • Persists across page navigation
  • Visible alongside the page
  • Full chrome.* API access
  • Can run indefinitely while open
  • Right for: research, history, assistants
Popup
  • Closes on any click outside
  • Overlays the page, then disappears
  • Full chrome.* API access
  • Dismissed automatically
  • Right for: quick actions, settings

Opening the Panel

// In background.js — open the panel programmatically
chrome.sidePanel.open({ windowId: tab.windowId });

// Or configure action button to open panel instead of popup:
await chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true });

NeuralTab's Side Panel

The sidepanel.html shows the active tab's title and URL, session visit counts, storage usage, and a live navigation feed driven by chrome.storage.onChanged. It updates in real time as you browse — demonstrating the key advantage of the side panel over the popup: persistence.
