Module 17 — Cross-Browser Compatibility

Write once, ship on Chrome, Firefox, and Safari — with minimal per-browser branching.

The Core Strategy

One manifest, one codebase, two adjustments: (1) a polyfill that makes browser.* available in Chrome, (2) feature detection guards before every Chrome-exclusive API call. Everything else — storage, tabs, scripting, alarms, messaging — is compatible across all three browsers.

The Polyfill Pattern

// In any extension script:
if (typeof browser === 'undefined') {
  // We're in Chrome — browser_polyfill.js created window.browser
}
// Use browser.* everywhere:
const tabs = await browser.tabs.query({ active: true });
// Works: Chrome (polyfilled), Firefox (native), Safari (native)

Feature Guards

// Guard Chrome-exclusive features:
if (chrome.sidePanel) {
  await chrome.sidePanel.open({ windowId });
}
if (chrome.offscreen) {
  await chrome.offscreen.createDocument({...});
}
// NTCompat helpers:
if (window.NTCompat?.hasSidePanel()) { ... }

What Doesn't Cross

chrome.debugger (CDP) — Chrome only. chrome.sidePanel — Chrome only. chrome.offscreen — Chrome only. chrome.storage.session — Chrome MV3 and Safari MV3, not Firefox MV2. Plan your feature set around the common denominator if full cross-browser support is required.
