Module 18 — React + Vite + TypeScript

Production-grade build pipeline for Chrome extensions: hot reload for UI, TypeScript for correctness, Vite for speed.

Project Structure

module_18/

├── vite.config.ts          ← vite-plugin-web-extension config

Getting Started

npm install
npm run dev      # watch mode — rebuilds on save
# Load dist/ as unpacked extension in Chrome

npm run build    # production build
npm run typecheck # TypeScript errors without building

Key Constraint: SW Cannot Be an ES Module with importScripts

When manifest.json sets "type": "module" for the background, importScripts() is unavailable. All imports must be bundled by Vite. When using "type": "classic", you lose native ESM but regain importScripts. Vite's plugin handles this by default — it bundles everything for the SW regardless of type.
