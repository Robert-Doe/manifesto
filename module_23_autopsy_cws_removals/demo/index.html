Module 23 — CWS Policy Removals

Real cases. Real consequences. The history of Chrome Web Store enforcement shapes every design decision in a published extension.

Timeline of Major Enforcement Actions

2012
Chrome Web Store launches with self-certification
Extensions submitted with minimal review. The wild west era.
2014
Inline installs removed for off-store extensions
First major policy tightening. All installs must go through CWS.
2018
Stylish removed — 1.8M users' history harvested
Privacy disclosure requirements introduced shortly after.
2019
DataSpii — 8 extensions exfiltrating history
Led to stricter permission justification requirements.
2020
Manifest V3 announced
CSP restrictions designed to prevent remote code execution patterns.
2021
The Great Suspender force-disabled
First mass force-disable. Established that acquisitions are a risk vector.
2022
Privacy Practices tab mandatory in CWS dashboard
Incomplete privacy disclosure = submission rejection.
2024
MV2 phase-out begins for new submissions
MV3 required for all new extensions. MV3 CSP enforcement in effect.

The Pattern

Each enforcement action is followed by a policy change that would have prevented it. Build your extension assuming the next policy change will catch anything that skates on the edge of current policy. The safest extension is one where every permission is justified and all data stays on device.
