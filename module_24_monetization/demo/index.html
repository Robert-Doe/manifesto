Module 24 — Monetization

The business case for ethical extension monetization — without selling your users' data.

The Math

Freemium scenario: 10,000 DAU

Conversion rate: 5% → 500 paying users

Price: $4.99/month → $2,495/month

Annual: ~$30,000/year

Comparison: selling browsing data for 10,000 users ≈ $50-200/month from data brokers. The freemium model is 10-20× more valuable AND doesn't violate CWS policy.

Local Analytics vs. Remote Analytics

// NeuralTab: local only — never leaves device
await AnalyticsManager.track('feature_use', { feature: 'history_search' });
// Stored in chrome.storage.local — 30-day rolling window
// User can inspect, export, or delete at any time

// Typical remote analytics (e.g. Mixpanel):
mixpanel.track('feature_use', { feature: 'history_search', userId: '...' });
// Sent to third-party server — user has no control

License Key Pattern

Background service worker validates the license key against your server. Result is cached for 24 hours. Features check isPremium() — enforced server-side, not bypassable from the popup UI.

Recommended Platforms

LemonSqueezy — developer-friendly, handles VAT/tax globally, good API for license key generation. Gumroad — simple, trusted brand, lower conversion friction. Stripe — maximum control, requires more backend setup. All work well as the payment layer behind a server-validated license key.
