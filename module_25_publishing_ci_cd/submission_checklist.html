Manifest & Permissions0/5
manifest_version: 3 CRITICAL
MV2 extensions are no longer accepted for new submissions.
No unused permissions
Every permission in manifest.json must be used. Remove debugger, identity, etc. if not in use.
<all_urls> justified in listing description
If you request <all_urls>, the CWS listing must explain why clearly.
No remote script loading CRITICAL
All JS must be bundled in the extension. No eval, no remote script tags, no importScripts from CDN.
No obfuscated code CRITICAL
Minification is fine. Obfuscation (mangled variable names, encoded strings) triggers rejection.
Privacy & Data0/4
Privacy policy URL set in CWS dashboard
Required if you collect any user data, including analytics.
Data use disclosure completed in CWS dashboard
The "Privacy practices" tab in the developer dashboard must be filled out accurately.
No user data sold to third parties CRITICAL
Selling browsing history, usage data, or any user-derived data to data brokers is a removal offense.
No keystroke logging or form content capture
Recording what users type and sending it off-device requires explicit consent and strong justification.
Listing Quality0/5
Screenshots show actual extension UI
Screenshots must show your real extension, not stock photos or misleading mockups.
Description matches actual functionality
Do not describe features you don't have. Do not use keyword stuffing.
128×128 icon (PNG, no alpha edge issues)
Icon must look good on both light and dark backgrounds in the CWS listing.
1280×800 or 640×400 promotional tile (optional but recommended)
Extensions with promo tiles get better placement in search results.
Category set correctly
Wrong category increases likelihood of manual review delays.
Technical Quality0/5
Tested on clean Chrome profile
Install from the .zip on a fresh profile with no other extensions. Verify all features work.
No console errors in background, popup, options
Open DevTools on each page. Zero uncaught errors required before submission.
Service worker does not crash on install
Check chrome://serviceworker-internals after install. Status should be RUNNING or STOPPED, not REDUNDANT.
Zip file excludes development artifacts
No node_modules/, .git/, .env, *.map files, test files, or README in the submission zip.
Version number incremented from previous submission
CWS rejects updates with the same version number as a published version.
